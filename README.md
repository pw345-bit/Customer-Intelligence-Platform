# 🌿 Bloom Customer Intelligence Platform

An interactive **Machine Learning dashboard** that analyzes customer behavior, predicts churn risk, and helps businesses improve customer retention.

### ✨ Features
- 📊 Interactive customer analytics
- 🤖 ML-based churn prediction
- 🎯 Customer risk segmentation
- 📈 Visual insights and KPI metrics
- 👤 Individual customer risk profiles
- 💡 Personalized retention recommendations

### 🎯 Project Goal
To help businesses identify customers who may leave and take proactive steps to improve customer loyalty.

### 🛠️ Tech Stack
Python • Streamlit • Pandas • Scikit-learn • Plotly

### 🚀 Getting Started

pip install -r requirements.txt
streamlit run app.py


### 🔮 Future Scope
- Real-time customer churn monitoring
- Email alerts for high-risk customers
